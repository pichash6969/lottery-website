# 🎰 Multi-Page Lottery Website

A complete lottery system with 2D and 3D draws, user management, and betting features.

## Features
- 2D/3D Lottery System
- User Login/Signup
- Virtual Coin Betting
- VIP Levels
- Redeem Code System
- Leaderboard
- Mobile Responsive

## Live Demo
[View Website](https://yourusername.github.io/lottery-website/)

## How to Use
1. Sign up for an account
2. Get 500 starting coins
3. Place bets on 2D/3D numbers
4. Win coins based on draw results
5. Use redeem codes for extra coins

## Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage for data persistence
